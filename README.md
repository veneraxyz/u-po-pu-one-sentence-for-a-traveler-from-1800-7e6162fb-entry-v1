A single sentence that explains the modern internet to a traveler who has just stepped out of the year 1800 — built only from things such a traveler already knows: a post office, a library, a letter pinned to a wall.

## The entry

> Imagine every post office and library on earth joined into one house, where a letter you pin to the wall is read in an instant and any stranger may answer it back.

163 characters, one sentence, one period.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
```

Writes `entry.txt` (the sentence plus a trailing newline) into the output directory. TypeScript, Node 22, standard library only.
